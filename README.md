Single-page demo for **FarMore Construction LLC** — docks, boat lifts and seawalls in
Indian Rocks Beach, FL and the Pinellas beaches. Built by Wilson Innovations as a
demo-first pitch (the business currently runs a generic Wix site).

- **Live:** https://wilsoninnovations.net/farmore-construction/
- **Stack:** single self-contained `index.html`, inline CSS + minimal JS. Works from
  `file://` and with JS disabled.
- **Fonts:** Ruda (display) + Archivo Narrow (body), Google Fonts.
- **Palette:** deep harbor-navy + weathered-teak + white-hull.
- **Status:** `noindex` demo — remove the noindex meta when the site goes live.
